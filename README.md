## 🚀 Getting Started

Each project folder is self-contained. To run any individual project:

### Frontend Web Apps (BANKIST, GUESS-MY-NO, PIG-GAME, Projects, Projects-1)
Simply open the index.html file in any modern web browser or use a live server extension:
`ash
# Example for BANKIST
cd BANKIST
# Open index.html in your browser
`

### Full-Stack / AI Projects (pdf-qa-bot)
Refer to the dedicated [pdf-qa-bot/README.md](./pdf-qa-bot/README.md) for environment configuration, backend setup, and Docker instructions:
`ash
cd pdf-qa-bot
npm install
npm run start
`
